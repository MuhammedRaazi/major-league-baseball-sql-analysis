# Major League Baseball SQL Data Analysis

A SQL-based data analysis project exploring historical Major League Baseball (MLB) data using advanced SQL concepts and analytical querying techniques.

---

## Project Overview

This project analyzes a real MLB database across multiple analytical areas including player careers, salaries, schools, and team statistics.

The goal of this project was to strengthen practical SQL skills by solving real-world analytical problems using structured queries, aggregations, joins, CTEs, and window functions.

---

## Analysis Areas

### School Analysis

* Universities producing the most MLB players
* Player production trends across decades
* Top schools contributing to professional baseball

### Salary Analysis

* Top spending teams
* Cumulative payroll analysis
* Teams reaching $1B spending milestones
* Salary distribution trends

### Player Career Analysis

* Average debut age
* Career longevity analysis
* Team loyalty patterns
* Decade-wise player trends

### Player Comparison Analysis

* Shared birthdays
* Batting handedness analysis
* Physical attribute comparisons
* Historical player trends
